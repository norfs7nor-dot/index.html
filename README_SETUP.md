Setup instructions for XMONE Platform (Arabic)

1) تشغيل SQL لإضافة جدول profiles
- افتح مشروعك في Supabase → SQL Editor
- أنشئ ملفًا جديدًا وألصق محتويات: sql/001_create_profiles.sql
- نفّذها (Run)

2) تأكد من إعدادات Authentication
- Supabase → Authentication → Settings
- تأكد من تفعيل Email provider
- إذا أردت تجاوز تأكيد البريد لتجارب سريعة: قم بإيقاف "Confirm email" مؤقتًا

3) اختبار الموقع
- افتح index.html في المتصفح (أو انشره على استضافة بسيطة)
- أنشئ حساب جديد ثم سجّل الدخول
- بعد تسجيل الدخول، تفقد رصيدك واضغط "تشغيل التعدين"

4) أمان
- المفتاح المضمن في index.html هو "anon public key" ويُستخدم على جهة العميل فقط.
- إذا كان المستودع عامًا، يُنصح بتدوير المفتاح (Rotate key) بعد الاختبار.
- للاستخدام الإنتاجي: استخدم متغيرات بيئة أو خدمة تخفي المفاتيح بدلاً من وضعها مباشرة في المستودع.

5) مشاكل شائعة
- خطأ permission denied عند القراءة/الكتابة: تأكد أنك شغلت SQL لإنشاء جدول profiles وتفعيل السياسات.
- خطأ مرتبط بالجلسة: تأكد من أن المستخدم أكمل عملية التفعيل في حال كنت تستخدم تأكيد البريد.

إذا أردت، أستطيع أيضًا أن أساعدك خطوة بخطوة عبر شاشة مشتركة (ترسل لي نتائج كل خطوة) أو أغيّر الملف ليقرأ المفتاح من متغيرات بيئة في حال كنت تنشر عبر خدمة استضافة تدعم ذلك.
